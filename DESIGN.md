# Design — панель дежурного Sentinel

Один файл `src/sentinel/web/index.html`, без сборки и внешних ресурсов (CSP: только `'self'` и inline).
Описание снято с построенной панели; при изменении панели обновляйте этот файл.

## Мир

Консоль дежурного для длинной смены: графитовые поверхности, состояния как сигнальные лампы.
Цвет несёт смысл и только его.

- **Фиолетовый** — то, что *предложила нейросеть*: шаги поиска и модели в каскаде, их сегменты на шкале
  уверенности, выбранная инструкция, рамка объяснения модели (пунктир, пометка «недоверенный текст»).
- **Нейтральный каркас** — символьный слой (детектор, верификатор, политика, исполнитель).
- **Лампы состояний**: янтарная — ждёт решения (пульсирует), зелёная — устранён / проверка пройдена,
  красная — передан человеку / отклонено, сине-серая — в работе.
- **Акцент** (бирюзовый) — только интерактивность: основная кнопка, фокус, выделение.

## Токены

Задаются на `:root[data-theme="dark"|"light"]`. Тёмная тема по умолчанию (рабочее место), светлая — для
печати и снимков в записку (`?theme=light` или кнопка в шапке, выбор хранится в `localStorage`).

| Роль | Тёмная | Светлая |
|------|--------|---------|
| фон / поверхность / вторая / третья | `#0e1216` / `#151a20` / `#1b222a` / `#232c36` | `#eef1f4` / `#fff` / `#f4f6f8` / `#e8ecf0` |
| текст 1 / 2 / 3 | `#e7ebf0` / `#aab4c0` / `#808b99` | `#141a21` / `#48525f` / `#636e7c` |
| акцент | `#4fc0d3` | `#0e7c90` |
| шкала: модель / поиск / сигналы | `#957eef` / `#5e4cbc` / `#1a9cb0` | `#6d4fd8` / `#a690f2` / `#0f8aa0` |

Палитра шкалы проверена валидатором dataviz (полоса светлоты, хрома, различимость при дальтонизме);
предупреждение о контрасте закрыто подписями и легендой со значениями.

Шрифты системные: `system-ui` для интерфейса, моноширинный только для идентификаторов, сигналов, действий и
данных журнала. Числа — `tabular-nums`, десятичная запятая. Радиусы 6 / 10 / 14 px, отступы кратны 4 px.

## Композиция

Шапка (конфигурация системы чипами, подключение, тема) → слева очередь с сегментным фильтром
(Все / Решение / В работе / Закрыты) и демо-управлением → справа карточка:

1. Заголовок: идентификатор, лампа и состояние, правило детектора, сигналы, целостность хэш-цепочки.
2. Блок решения (только при ожидании, эскалации или устранении): действие и параметры, инструкция,
   сработавшие правила политики с пояснением, кнопки «Подтвердить действие» / «Отклонить».
3. **Каскад решения** — шаги, восстановленные из журнала аудита, на вертикальной оси с узлами-иконками.
   Время имитатора показывается только при изменении.
4. Итоговая уверенность: крупное число, сегментированная шкала (вклады `w·x`, зазор 2 px) с отметками
   порогов P5/P6 из `/config`, расшифровка слагаемых.
5. Найденные инструкции, время этапов, журнал аудита (сворачиваемый, с прокруткой).

## Правила

- Недоверенный текст (модель, логи) — только `textContent`; тест проверяет отсутствие `innerHTML`.
- Карточка перерисовывается только при изменении данных (опрос раз в 3 с не сбрасывает прокрутку).
- Без декоративной анимации: пульсирует лишь лампа «ждёт решения»; `prefers-reduced-motion` отключает её.
- На ширине < 980 px колонки складываются, шапка перестаёт быть липкой; горизонтальной прокрутки страницы нет.
