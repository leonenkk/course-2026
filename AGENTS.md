# Sentinel — контекст для агентов

Гибридная система (символы + нейросети) обнаружения, диагностики и реагирования на инциденты.
Курсовая работа БГУИР (7 семестр), затем основа диплома (платформа RELAY). Язык проекта — русский
(докстринги, комментарии, README); идентификаторы в коде — латиница.

## Команды

```bash
uv venv && uv pip install -e ".[api,dev]"   # окружение (Python >= 3.11)
.venv/bin/python -m pytest                  # все тесты (~5 с), должны быть зелёными
.venv/bin/ruff check src tests              # линтер
.venv/bin/python -m sentinel all            # сценарии С1–С6 на имитаторе
.venv/bin/python -m sentinel run c6         # один сценарий с протоколом аудита
.venv/bin/python -m sentinel run c1 --llm ollama --model <модель>   # с реальной моделью
```

## Архитектура (кратко)

Конвейер: `detector → agent/context → knowledge (поиск) → llm → agent/verifier → policy → tools/executor →
проверка результата → audit`. Оркестратор — `src/sentinel/agent/orchestrator.py`, сборка — `system.py`.
Все внешние зависимости за интерфейсами (`ServiceAdapter`, `LLMClient`, `Embedder`, `AuditStore`):
менять реализации, а не ядро. Подробная карта — в `README.md`, план — в `docs/ROADMAP.md`.

## Инварианты (не ломать)

- Решение о действии принимает только символьный слой. Ответ модели — недоверенное предложение:
  он проходит проверки V2–V5 и политику P1–P7, итоговый вердикт — наиболее строгий из сработавших.
- Исполняются только действия из реестра (`tools/registry.py`); повтор того же действия блокируется
  ключом идемпотентности. Действия высокого риска — только с подтверждением человека.
- Текст логов — недоверенные данные: очищается, помечается, не попадает в инструкции модели.
- Каждый шаг пишется в журнал аудита (хэш-цепочка). Недопустимый переход состояний — ошибка.
- Идентификаторы сигналов, действий, инструкций, правил едины для БЗ, ответа модели, политики и журнала.

## Связь с пояснительной запиской

Параметры в `config.py` (пороги, веса, периоды) взяты из раздела 2 записки; сигналы, правила D/P/V/К и
состояния соответствуют таблицам и рисункам раздела. Записка — отдельный Overleaf-проект вне этого
репозитория (LaTeX, собирается `pdflatex -shell-escape` + bibtex). При изменении параметра или правила
в коде обновляйте записку, и наоборот. Исходники диаграмм — `docs/figures/` (matplotlib).

## Подводные камни

- `StubLLM` и `HashingEmbedder` — тестовые двойники, **не нейросети**; не выдавать их результаты за
  результаты нейросетевого компонента.
- Модели < 3B параметров плохо справляются с форматом и выбором инструкции (см. README).
- Журнал и исполнения — SQLite (`check_same_thread=False`); в целевой архитектуре — PostgreSQL.
- API требует токен (`SENTINEL_API_TOKEN`), `/demo/*` только при `SENTINEL_DEV=1`. Не добавлять
  маршруты без проверки токена.
- Не коммитить `.venv`, секреты, `.env`. Не пушить без просьбы владельца.
